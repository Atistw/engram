# todo-pane：在側邊窗格看 TASKS（選用）

> **一句話定位**：把 `TASKS.md` 的 🎯 我要做、👀 我在追、📅 近期日程顯示在 Claude 介面旁邊的窗格。只讀不寫，每分鐘和每輪對話結束後自動重讀。

## 它做什麼，不做什麼

| 做 | 不做 |
|---|---|
| 🎯 顯示未完成的編號項目、數量與上限 8，超過上限會標出來 | 不改 TASKS，不幫你打勾 |
| 超過 21 天沒更新的條目變灰並顯示天數 | 不搬到 🟡（那是週五庫管家的事） |
| 👀 一人一行顯示，支援「`- **姓名**：…`」與「`### 姓名` 一人一節」兩種寫法 | 不追蹤對方有沒有交 |
| 📅 顯示今天以後的前 6 個日期 | 過去的日期與範例列略過 |
| 「複製」按鈕把 🎯 或 👀 複製成可以貼給別人的文字：拿掉「待確認」「待你」這類寫給自己的註記，把你的名字換成「我」 | 不送出任何訊息 |
| 讀到 `停讀邊界` 註解就停 | 不讀 🟡 與系統維護區 |

## 前提

Claude Code 要夠新、支援 mod 與側邊窗格。作者在桌面版 2.1.308 跑過測試。

## 安裝

1. 把本資料夾複製到 `~/.claude/mods/todo-pane`，在 `~/.claude/settings.json` 的 `env.CLAUDE_CODE_PLUGIN_DIRS` 加入這個路徑（多個 mod 用 `;` 分隔，macOS 與 Linux 用 `:`）。
2. （選用）建立 `~/.claude/todo-pane.json`：

   ```json
   { "tasks": "D:/my-vault/TASKS.md", "selfName": "王小明" }
   ```

   | 欄位 | 作用 |
   |---|---|
   | `tasks` | TASKS.md 的完整路徑。不填就讀 session 起始目錄的 `TASKS.md`，所以在知識庫資料夾開 session 時不用設 |
   | `selfName` | 你在 TASKS 裡怎麼稱呼自己。複製給別人時換成「我」；不填就不換 |

3. 開一個新 session。窗格會自動打開；關掉後輸入 `/todo` 再打開。

## TASKS 寫法要對得上

窗格依 Engram 範本的格式解析：

- 區塊標題含「我要做」「我在追」「近期日程」。
- 🎯 每條是 `1. [ ] **標題**〔性質〕(更新 MM-DD)`；`- [ ]` 開頭的私人待辦不算進上限。
- 近期日程是表格，第一欄 `MM/DD`。

改了區塊標題名稱，窗格就讀不到那一塊。

## 已知限制

- 驗證範圍：7 項解析測試（`claude plugin test`），只測解析與複製文字，**沒有測窗格畫面**。作者自己的庫用的是舊的寫死路徑版本；這個可設定的版本沒有在真實 session 實測過。
- 日期只有月日，跨年時以「離今天最近的那一年」推算。
