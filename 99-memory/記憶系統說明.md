# 記憶系統說明

---

## 這個資料夾放什麼

Claude 需要跨對話記住的事情，都放在這裡。分四種類型：

| 類型 | 說明 | 範例 |
|------|------|------|
| **user（關於你）** | 你的角色、目標、知識背景、偏好 | 你是做什麼的、你擅長什麼 |
| **feedback（協作風格）** | Claude 應該怎麼跟你合作 | 「少問直接做」、「不要給我條列式」 |
| **project（專案狀態）** | 正在進行的工作、關鍵決策、重要時間點 | 某個專案的當前狀態 |
| **reference（外部資源）** | 去哪裡找什麼資訊 | 某個文件在哪、某個系統的帳號 |

---

## 怎麼新增記憶檔案

直接告訴 Claude：
> 「把這件事記下來：[內容]」

或是：
> 「幫我建一份人物側寫放進 99-memory/」

Claude 會自動建立格式正確的 `.md` 檔案，並更新 `MEMORY.md` 索引。

---

## 記憶檔案的格式

```markdown
---
name: 檔案名稱（英文或中文都可以）
description: 一行說明——這份記憶是關於什麼的
metadata:
  type: user / feedback / project / reference
---

> **一句話定位**：這份記憶的核心用途

記憶內容...

**Why:** 為什麼要記這件事
**How to apply:** 什麼情況下 Claude 應該調用這份記憶
```

---

## 什麼不需要記

- 已經在程式碼或文件裡的東西（Claude 可以直接讀）
- 只用一次的臨時資訊
- 可以用 Google 查到的通用知識
- **行為規則（「Claude 收到 X 時要做 Y」）**——這類規則放 Claude 偏好設定（每輪重新注入，不會被長對話沖掉）或 skill（觸發當下載入），寫在記憶檔裡長對話後必被遺忘。記憶檔只放規則的「為什麼」和格式細節

---

## 定期整理

每隔一段時間，問 Claude：
> 「讀一下我的 99-memory，哪些記憶可能過期或不準了？」

Claude 會幫你清理或更新。
