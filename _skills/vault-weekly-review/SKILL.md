# 知識庫週回顧流水線

每週一次的回饋層掃描。目的不是整理，是**回頭驗證判斷**：上週決的事成立嗎、放手的事放得住嗎、庫還跟得上現實嗎。知識庫根目錄：使用者在 Cowork 選定的工作資料夾（以下路徑相對於庫根目錄）。

## 素材載入（步驟 0）

依序讀入，長檔分段讀：

1. 當週週報 `02-日常運作/週報/YYYY-WXX_週報.md`（不存在則改讀當週會議記錄 + 週記）
2. 當週週記 `02-日常運作/raw/YYYY-WXX_週記.md`
3. `DECISIONS.md` 全文
4. `TASKS.md` 全文
5. 個人決策原則/預警清單檔（若你有維護這類檔案）
6. 放手/授權觀察記錄檔（若你有培養或交接對象，見步驟 2）
7. `99-memory/MEMORY.md` 索引

## 執行順序（依序跑完，不跳步）

### 步驟 1｜決策回驗掃描

掃 DECISIONS.md 中 `validated` 為空的已決項目與「近期已決」表：

- 對照本週素材，**有新證據可佐證結果的** → 補 `validated`（成立 / 修正 / 否定 + 一句話），同步更新對應決策案例檔的 frontmatter
- 無新素材的 → 維持待驗，不硬填
- 「醞釀型」項目逐條檢查：等的信號本週出現了嗎？預計時間過了嗎？過期未決的列入報告「過期醞釀」段

### 步驟 2｜放手追蹤（選用，僅適用於有培養/交接對象的使用者）

若你正在培養接班人或把工作放手給團隊，維護一份「放手觀察記錄」（例如 `01-組織與關係/放手觀察記錄.md`，單一來源，不另開新檔）。掃本週會議記錄與週記中相關人物的場次，檢查每場是否已有樣本記錄；遺漏的補記，已記錄的不重複。

然後給**週級判定**：每條線本週是「自轉／要推才動／回流到我」三態中的哪一態。連續兩週「回流」的線，明確標「放手此線失效，建議檢視」。

沒有培養/交接對象的使用者跳過本步驟。

### 步驟 3｜盲點四視角（週彙總層級）

對本週整體（非單一事件）跑四視角，只報**結構性新發現**，不重複已知：

1. **接班/替代視角**：本週哪件事若你不在位就會斷？
2. **下游依賴**：本週誰的產出依賴你的隱性輸入而他不自知？
3. **時間衰退**：庫內哪個仍在引用的前提，本週的事實已經動搖了？
4. **反向確認**：你本週在補誰的位而那個人不知道？

掃到的按類型歸入 DECISIONS.md 對應分類標日期；時間衰退型附「繼續/修正/放棄」三選一建議與證據。

### 步驟 4｜庫腐化檢查

機械式清單，逐項查：

- **TASKS 膨脹**：數「🎯 我要做」條數；超過 8 條連續兩週標紅。另數「🟡 待確認還活著」條數
- **殭屍任務**：`(更新 MM-DD)` 超過 21 天的條目，列出建議「做/砍/降級」（週五庫管家會把它們移到 🟡）
- **週記缺檔**：當週週記是否存在；不存在代表 append 規則沒被執行，記一筆
- **記憶索引一致性**：MEMORY.md 索引行數與 99-memory/ 實際檔數是否對得上；孤兒檔或斷鏈列出
- **DECISIONS 月掃到期**：「下次月掃」日期是否已過；已過則提醒
- **vault-check**：跑 `bash 10-操作手冊/vault-check.sh`，FAIL 項逐條列進報告（只列不改）

### 步驟 5｜產出週回顧報告

存入 `02-日常運作/回顧/YYYY-WXX_週回顧.md`（資料夾不存在則建立）：

```yaml
---
tags: [週回顧, 日常運作]
week: YYYY-WXX
updated: YYYY-MM-DD
related: ["[[DECISIONS]]", "[[TASKS]]"]
---
```

結構固定五段：① 回驗結果（補了幾筆 validated、過期醞釀）② 放手週判定（若適用；不適用則省略本段）③ 盲點新發現（無則寫「本週無結構性新發現」，不硬掰）④ 庫健康（腐化檢查結果，紅/黃/綠一行結論）⑤ 給自己的一個問題（本週最值得花 5 分鐘想的一件事，只挑一個）。

### 步驟 6｜寫回與收尾

- validated 補寫 → DECISIONS.md + 對應決策案例檔
- 放手追蹤補記（若適用）→ 對應觀察記錄檔
- 殭屍任務處置建議 → 標註在 TASKS.md 對應項目後（不直接刪，等使用者拍板）
- `CHANGELOG.md` 頂部補一行（HOME 不設「最近更新」區，變更一律直寫 CHANGELOG）

## 結尾統一回報（固定格式）

```
✅ 週回顧完成｜YYYY-WXX
回驗：補 N 筆 validated（成立 X / 修正 Y / 否定 Z）｜過期醞釀 N 項
放手：（各線=態，或「不適用」）
盲點：N 項新發現（或「無」）
庫健康：紅/黃/綠｜主因一句話
本週一問：（一句話）
```

## 邊界

- 本 skill 只驗證與回饋，**不代決**——所有處置建議（砍任務、失效判定、修正決策）都標「待使用者拍板」
- 與 transcript-intake 分工：單場逐字稿進來走 transcript-intake（事件層），本 skill 只在週級彙總跑（回饋層），不重做單場入庫

## 客製提示
這份 SKILL.md 是通用版，步驟 2（放手追蹤）為選用段。你可以依自己的組織情境調整或補上額外的週彙總檢查項，改完重新打包安裝即可。
