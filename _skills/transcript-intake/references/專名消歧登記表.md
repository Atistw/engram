# 專名消歧登記表（快照）

這是給**庫外環境**（例如在 Cowork 把本 skill 裝起來、讀不到知識庫時）用的快照。

- **正本在知識庫**：`10-操作手冊/專名消歧登記表.md`。能讀到知識庫時一律讀正本。
- **新變體只補正本**，不補這份快照。讀不到、寫不進知識庫時，把新變體列在入庫回報的「待補登記表」，請使用者補。
- 想讓庫外環境也查得到最新內容：把正本內容複製到這裡，重新打包安裝 skill。

## 已知易混組（範例格式）

### 產品／平台／系統名
- 範例：產品全名（≠ ASR 常見誤寫 變體1／變體2）

### 人名
- 範例：暱稱＝全名（角色）；容易被 ASR 混成同一人的部屬／同事

### 客戶／公司名
- 範例：客戶全名曾被裂成音近 變體1／變體2
